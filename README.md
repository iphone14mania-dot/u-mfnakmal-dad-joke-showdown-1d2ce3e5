A tiny Node program that writes one short text to `/output/entry.txt` — one dad joke, written to be told out loud. The wife sets it up, the father answers with the pun: "the yeast of my worries", a twist on the everyday idiom, swapped for the bread the setup just named. Clean first-read pun, punchline at the very end. 79 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
